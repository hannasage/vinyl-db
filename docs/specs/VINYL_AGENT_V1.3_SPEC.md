# Vinyl Collection Agent v1.3 Specification

## Overview

Building on the successful chat-based vinyl collection management system in v1.2, v1.3 introduces **cost optimization through embeddings and enhanced RAG efficiency**. The primary goal is to reduce OpenAI API costs while maintaining or improving the quality of responses.

## 1. Cost Analysis & Optimization Strategy

### 1.1 Current Cost Drivers

**Primary Cost Sources:**
- **Large Context Windows**: Full conversation history sent to GPT-4o-mini
- **Redundant Data Processing**: Same album/artist data processed multiple times
- **Inefficient RAG**: Large result sets sent to LLM for summarization
- **Verbose Prompts**: Long system prompts with extensive examples

**Estimated Current Costs:**
- Average tokens per request: ~2,000-4,000
- Cost per interaction: ~$0.01-0.02
- Monthly cost for active user: ~$5-15

### 1.2 Optimization Targets

**Goal: 60-80% cost reduction**
- Reduce average tokens per request by 70%
- Use GPT embeddings for semantic search (text-embedding-3-small model)
- Optimize prompt engineering
- Implement result summarization at database level

### 2.2 Embedding Generation Strategy

**OpenAI GPT Embeddings Integration:**
- **Model**: `text-embedding-3-small` (1536-dimensional vectors)
- **Cost**: ~$0.00002 per 1K tokens (very cost-effective for embeddings)
- **Performance**: State-of-the-art semantic similarity for English text
- **Integration**: OpenAI API calls from Supabase Edge Functions

**When Embeddings Are Generated:**
- **Album Creation**: Generate embeddings for new albums
- **Artist Creation**: Generate embeddings for new artists
- **Batch Processing**: Generate embeddings for existing data
- **Query Processing**: Generate embeddings for user queries

**Embedding Sources:**
- **Album Title**: Clean, normalized album name
- **Artist Name**: Clean, normalized artist name
- **Combined**: "Album Title by Artist Name" format
- **Temporal**: "Album Title by Artist Name released in [year] purchased [date] received [date]" format
- **Query**: User's search query (normalized)

## 4. Technical Implementation Details

### 4.1 Embedding Generation with OpenAI API

**Supabase Edge Function for Embedding Generation:**
```typescript
// supabase/functions/generate-embedding/index.ts
import { createClient } from '@supabase/supabase-js';
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const supabase = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
);

export async function generateEmbedding(text: string): Promise<number[]> {
  const response = await openai.embeddings.create({
    model: 'text-embedding-3-small',
    input: text,
  });
  
  return response.data[0].embedding;
}

export async function generateAlbumEmbeddings(albumId: number): Promise<void> {
  // Get album and artist data
  const { data: albumData, error: albumError } = await supabase
    .from('album')
    .select(`
      title,
      release_year,
      purchased_date,
      received_date,
      artist:artist_id(name)
    `)
    .eq('id', albumId)
    .single();
  
  if (albumError) throw albumError;
  
  const { title, release_year, purchased_date, received_date, artist } = albumData;
  const artistName = artist.name;
  
  // Generate text representations
  const combinedText = `${title} by ${artistName}`;
  
  let temporalText = `${title} by ${artistName}`;
  if (release_year) temporalText += ` released in ${release_year}`;
  if (purchased_date) temporalText += ` purchased ${purchased_date}`;
  if (received_date) temporalText += ` received ${received_date}`;
  
  // Generate embeddings
  const [titleEmbedding, artistEmbedding, combinedEmbedding, temporalEmbedding] = await Promise.all([
    generateEmbedding(title),
    generateEmbedding(artistName),
    generateEmbedding(combinedText),
    generateEmbedding(temporalText)
  ]);
  
  // Store embeddings
  const { error: insertError } = await supabase
    .from('album_embeddings')
    .upsert({
      album_id: albumId,
      title_embedding: titleEmbedding,
      artist_embedding: artistEmbedding,
      combined_embedding: combinedEmbedding,
      temporal_embedding: temporalEmbedding,
      updated_at: new Date().toISOString()
    });
  
  if (insertError) throw insertError;
}
```

### 4.2 Unified Semantic Search Function

**`supabase/functions/semantic-search/index.ts`:**
```typescript
import { createClient } from '@supabase/supabase-js';
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const supabase = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
);

interface CollectionQueryRequest {
  query: string;
  searchType?: 'album' | 'artist' | 'temporal' | 'combined';
  limit?: number;
  similarityThreshold?: number;
}

async function performCollectionQuery(
  query: string, 
  searchType: string = 'combined',
  limit: number = 10, 
  threshold: number = 0.7
): Promise<any[]> {
  // Generate query embedding using OpenAI API
  const queryEmbedding = await openai.embeddings.create({
    model: 'text-embedding-3-small',
    input: query,
  });
  
  // Select appropriate embedding column based on search type
  let embeddingColumn = 'combined_embedding';
  switch (searchType) {
    case 'album':
      embeddingColumn = 'title_embedding';
      break;
    case 'artist':
      embeddingColumn = 'artist_embedding';
      break;
    case 'temporal':
      embeddingColumn = 'temporal_embedding';
      break;
    default:
      embeddingColumn = 'combined_embedding';
  }
  
  // Perform vector similarity search using pgvector
  const { data: results, error } = await supabase.rpc('match_albums_by_type', {
    query_embedding: queryEmbedding.data[0].embedding,
    embedding_column: embeddingColumn,
    match_threshold: threshold,
    match_count: limit
  });
  
  if (error) throw error;
  return results || [];
}
```

**Database Function for Vector Similarity Search:**
```sql
-- Function to perform vector similarity search
CREATE OR REPLACE FUNCTION match_albums_by_type(
  query_embedding VECTOR(1536),
  embedding_column TEXT,
  match_threshold FLOAT DEFAULT 0.7,
  match_count INT DEFAULT 10
)
RETURNS TABLE (
  album_id BIGINT,
  title TEXT,
  artist_name TEXT,
  release_year INTEGER,
  purchased_date DATE,
  received_date DATE,
  similarity FLOAT
)
LANGUAGE plpgsql
AS $$
BEGIN
  RETURN QUERY EXECUTE format(
    'SELECT 
      ae.album_id,
      a.title,
      ar.name as artist_name,
      a.release_year,
      a.purchased_date,
      a.received_date,
      1 - (ae.%I <=> $1) as similarity
    FROM album_embeddings ae
    JOIN album a ON ae.album_id = a.id
    JOIN artist ar ON a.artist_id = ar.id
    WHERE 1 - (ae.%I <=> $1) > $2
    ORDER BY ae.%I <=> $1
    LIMIT $3',
    embedding_column, embedding_column, embedding_column
  ) USING query_embedding, match_threshold, match_count;
END;
$$;
```
